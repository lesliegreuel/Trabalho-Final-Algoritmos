## 📌 Sobre o projeto

Este projeto foi desenvolvido para a disciplina de **Algoritmos e Estruturas de Dados**.

O objetivo é desenvolver um programa capaz de **resolver expressões aritméticas**, permitindo que o usuário informe uma expressão e obtenha o resultado do cálculo.

O programa reconhece os operadores:

`+` &nbsp;&nbsp; `-` &nbsp;&nbsp; `*` &nbsp;&nbsp; `/`

Também são consideradas expressões com **parênteses**, **parênteses aninhados**, **números decimais** e **números negativos**.


## ⚙️ Como funciona

A resolução da expressão é realizada em três etapas. Primeiro, a expressão informada pelo usuário é analisada e dividida em seus respectivos termos, como operandos, operadores e parênteses, que são armazenados em uma fila na ordem em que aparecem. Em seguida, a expressão é convertida do formato infixado para o formato pós-fixado, utilizando uma fila para os termos da expressão, uma pilha para armazenar temporariamente operadores e parênteses e outra fila para armazenar a expressão pós-fixada. Por fim, a expressão pós-fixada é utilizada para realizar o cálculo e obter o resultado final.
